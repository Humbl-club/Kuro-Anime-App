Design decisions

The shared selected-book model is removed. Every read has its own chapter position and 44px advance key, directly beneath equal artwork. No extra selection, remote control bar or repeated Open buttons.

Cover and title are one detail target. Chapter advance is a separate sibling control. Completing a chapter updates only that read; opening details never changes progress. Existing failure, completion and Undo behaviour remains.

More chapter keys are visible, but each is next to its own title. This proposal needs your review; it is not an approved native design.
