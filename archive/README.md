Typical contents:
- superseded design snapshots
- old implementation summaries
- prior knowledge-base experiments
- generated codebase bundles
- point-in-time compatibility or rollout reports

Use archived docs only for historical context.

- `/Applications/Kuro/CURRENT_APP_STATE.md`
- `/Applications/Kuro/CURRENT_APP_STATE_PLAIN.md`
