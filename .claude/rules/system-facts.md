# Kuro context adapter

Root `AGENTS.md` defines durable stack/architecture rules. For current facts search
`CURRENT_APP_STATE.md` and follow dated evidence; `docs/modules/README.md` maps owners.
Do not reuse archived SupabaseService maps or copy live pool/tier/flags into defaults.
The `performance` route identifies capacity evidence. A target is not measured usage;
overall steady-state results never override a failed subgroup, cold miss or unrun stage.
The `catalog_intake` route requires checking actual workers, upstream mapping/provenance,
shared rate budgets and whether a replacement source is genuinely independent.
